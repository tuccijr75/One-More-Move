# Test deployment — Neocities

Owner-approved test host: https://manicmike.neocities.org/omm/

The static HTML5 build is generated by `npm run check`. The active source remains app/ and the approved branch feat/omm-2-web-first. Vercel is no longer the intended test host, but its existing deployment remains until this replacement is verified; no external public release is authorized.

## Manual first upload (no credential transfer)

Download the one-more-move-web artifact from the successful Core Validation run corresponding to the intended commit. Extract the ZIP. In the Neocities dashboard select manicmike, create a directory named omm, then upload the extracted files into that directory. Create omm/assets and put the images there. Do not upload the ZIP itself or replace any root files. Open https://manicmike.neocities.org/omm/ and test. Confirm the served files match the artifact; a visible page alone does not prove revision parity.

## Repeated authenticated upload (local only)

Requires Node 20+ and the checked-out, reviewed migration branch. Run `npm run check`, then `npm run deploy:check` for a dry run (no network access). To upload, set NEOCITIES_API_KEY in the local process environment from Neocities Settings for the manicmike site. Never put a key in the repository or chat. Run `npm run deploy:neocities` and remove the key from the process environment afterward.

On Windows PowerShell, input the API key without echo:
```powershell
$secret = Read-Host "Neocities API key" -AsSecureString
$env:NEOCITIES_API_KEY = [System.Net.NetworkCredential]::new("", $secret).Password
try { npm run deploy:neocities } finally { Remove-Item Env:NEOCITIES_API_KEY -ErrorAction SilentlyContinue; $secret.Dispose() }
```

The command rebuilds and runs tests, verifies the manifest, verifies the authenticated site identity, checks SHA-1 remote hashes, uploads only changed files under omm/ in one multipart request, and rechecks hashes. It never deletes files, writes outside omm/, or prints the credential. API documentation: https://neocities.org/api. Respect the host's rate limits.

## Evidence and gates

A successful dry run is not an upload. An authenticated success receipt and live mobile smoke test are required before marking Neocities operational. AICS and all other directories are excluded. Deployment approval is for the test directory only. No itch.io/Game Jolt changes or main-branch merge.

## Module migration

Starting with the grid extraction, upload all six canonical modules (`grid.js`, `ai.js`, `config.js`, `generation.js`, `movement.js`, `progression.js`) before replacing `game.js` and then `index.html`; all other files and the manifest must come from the same verified web artifact. No new credential storage. GitHub, including Actions secrets, must never hold API keys. The owner-uploaded previous baseline is operational; a new upload and device smoke test are required for each candidate.
